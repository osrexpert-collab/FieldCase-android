# שומת נזקים — אפליקציית אנדרואיד

ממלאים בטלפון את טופס "שומת נזקים" ומפיקים אותו כ-PDF במבנה של טופס המשרד.

## מה יש באפליקציה
- **רשימת שומות:** שומה חדשה, עריכה, שכפול ומחיקה. הכול נשמר בטלפון.
- **הטופס:** פרטי הרכב והבדיקה, שורות של מהות התיקון ופירוט חלפים (מתחילים בשורה אחת ומוסיפים עד 15) עם סוג (מקורי, תואם, משומש), טבלת העבודות ותאריך.
- **צילום לוחית:** מזהה את מספר הרישוי על הטלפון. **מיקום נוכחי:** ממלא את מקום הבדיקה.
- **הפקת PDF:** תצוגה של הטופס, ואז "שמור PDF / הדפס". במסך ההדפסה של אנדרואיד בוחרים "שמירה כ-PDF" או מדפסת. אפשר גם לשתף את הטופס.
- **הגדרות (החלפת פרטי השמאי והמשרד):** שם השמאי ומספר רישיון, שורת הכותרת, ת.ד., נייד, פקס, דוא"ל, שני לוגואים, חתימה באצבע, ושורות הטקסט וההערות בטופס. כפתור אחד מחזיר את פרטי המשרד המקוריים.

## איך מקבלים APK
**דרך GitHub, בלי להתקין כלום:**
1. יוצרים repository חדש ומעלים אליו את כל התוכן של התיקייה, כולל התיקייה הנסתרת `.github`.
2. בלשונית **Actions** מחכים כ-5 דקות ומורידים את **ShumaApp-apk**.
3. מעבירים את `app-debug.apk` לטלפון ומתקינים.

**דרך Android Studio:** פותחים את התיקייה (File → Open), ולוחצים Run או Build → Build APK(s).

## חשוב לדעת
- הנתונים נשמרים רק בטלפון. הסרת האפליקציה מוחקת את השומות.
- קובץ APK מסוג debug מתאים לשימוש אישי. להפצה צריך לחתום גרסת release.
- כדי לשנות שדות או טקסטים קבועים, עורכים את `app/src/main/assets/www/index.html`.
