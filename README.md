# חוות דעת שמאי — תוכנה ל-Windows

תוכנת שולחן עבודה למילוי חוות דעת שמאי והפקתה כ-PDF. ב-PDF מופיעים רק העמודים שבשימוש, בלי עמודים ריקים.

## התקנה
מורידים את `ShumaDesktop-Setup.exe` (מלשונית Actions ב-GitHub), מריצים ומאשרים. אין צורך להתקין .NET.
אם Windows מציג "Windows protected your PC", לוחצים "More info" ואז "Run anyway". זה קורה כי הקובץ לא חתום דיגיטלית.

## מה יש בתוכנה
- **פרטים:** כותרת (חוות דעת / אומדן הנזק), מספר, לכבוד, מצב הרכב, פרטי הרכב, נסיבות המקרה.
- **מוקדים:** כמה מוקדי נזק שצריך. לכל מוקד שם (למשל "הקדמי"), טבלת עבודות וטבלת חלקים בלי הגבלת שורות.
- **סיכום וירידת ערך:** סה"כ לכל מוקד ולכולם, מע"מ (כולל / לא כולל), נזק גולמי, ירידת ערך, הערות, לוט.
- **חשבון שכ"ט:** חישוב מע"מ וסכומים, עם אפשרות לצרף או לא.
- **תמונות:** הוספה עם תיאור, מוקטנות אוטומטית.
- **הגדרות משרד ושמאי:** כותרת, טלפונים, שם, מספר רישיון, חתימה סרוקה והערות ברירת מחדל.
- **שמירה:** כל תיק נשמר כקובץ `.shuma` (לחיצה כפולה פותחת אותו בתוכנה).

## פיתוח ב-Visual Studio
פותחים את `ShumaDesktop.sln` ב-Visual Studio 2022 (עם ".NET desktop development") ולוחצים F5.
יצירת PDF: ספריית QuestPDF (רישיון Community, חינם לעסקים עם הכנסה שנתית עד מיליון דולר).
