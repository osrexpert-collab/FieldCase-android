# תיק שמאי בשטח — אפליקציית אנדרואיד

אפליקציית שטח לשמאי רכב: תיקים, צילום נזקים ולוחית, זיהוי מספר רכב, מיקום GPS, הכתבה בעברית, אומדן עם מע״מ, ודוח שטח לשיתוף.
הכול נשמר בטלפון בלבד. אין שרת ואין חשבון.

## איך מקבלים APK (בלי להתקין כלום) — GitHub

1. פתח חשבון ב-github.com (חינם) ולחץ **New repository**. שם: `fieldcase`, אפשר Private.
2. בעמוד של ה-repository החדש לחץ **uploading an existing file**, וגרור לשם את **כל התוכן** של התיקייה `FieldCase` (כולל התיקייה הנסתרת `.github`).
   אם הגרירה לא מעלה את `.github`: לחץ **Add file → Create new file**, כתוב בשם `.github/workflows/build-apk.yml` והדבק את התוכן של הקובץ.
3. לחץ **Commit changes**. הבנייה מתחילה לבד.
4. עבור ללשונית **Actions**, לחץ על הריצה האחרונה (כ-5 דקות), ובתחתית העמוד הורד את **FieldCase-apk**.
5. בתוך ה-zip יש `app-debug.apk`. העבר אותו לטלפון ופתח. אנדרואיד יבקש לאשר "התקנה ממקורות לא ידועים" — אשר לקובץ הזה בלבד.

## איך בונים ב-Android Studio

1. התקן Android Studio (גרסה Koala ומעלה).
2. **File → Open** ובחר את התיקייה `FieldCase`. חכה לסיום Gradle Sync.
3. חבר טלפון עם USB debugging ולחץ ▶ Run, או **Build → Build APK(s)**.
   הקובץ נוצר ב-`app/build/outputs/apk/debug/app-debug.apk`.

## מבנה הפרויקט

```
app/src/main/
  java/il/shamai/field/MainActivity.kt   מעטפת: WebView + גשר Native (מצלמה, ML Kit, GPS, דיבור, קבצים)
  assets/www/index.html                  כל הממשק (HTML/JS), עובד גם בלי אינטרנט
  AndroidManifest.xml                    הרשאות: מצלמה, מיקום, מיקרופון
```

הממשק נטען מ-`https://appassets.androidplatform.net/assets/www/index.html` דרך `WebViewAssetLoader`, כך שהאחסון המקומי עובד והתמונות מוגשות מ-`/blobs/`.
כדי לשנות טקסטים, שדות או אזורים ברכב — ערוך את `index.html` (הקבועים `AREAS`, `KINDS`, `VAT` בראש הסקריפט).

## חשוב לדעת

- **הנתונים בטלפון בלבד.** הסרת האפליקציה או "ניקוי נתונים" מוחקים את כל התיקים. שמור גיבוי לתיקים חשובים.
- **APK מסוג debug** מתאים לשימוש אישי. להפצה לאחרים או ל-Google Play צריך לחתום גרסת release עם מפתח משלך (Android Studio: **Build → Generate Signed Bundle / APK**).
- דוח השטח הוא תיעוד ראשוני, לא חוות דעת שמאית חתומה.

## בנייה ובדיקה אוטומטית ב-GitHub

כל שינוי שעולה ל-`main` מפעיל שתי ריצות בלשונית **Actions**:

- **Build APK**: בונה את `app-debug.apk` (להורדה תחת **FieldCase-apk**).
- **Smoke test on emulator**: מתקין ומפעיל את האפליקציה על אמולטור אנדרואיד 11, מדפיס קריסות ושגיאות JavaScript,
  בודק את ה-API של משרד התחבורה, ומייצר הצעת תיקון ודוח לדוגמה כ-PDF (ב-artifact בשם **smoke-output**).

בדיקת ה-PDF מופעלת רק בגרסת debug, עם `adb shell am start -n il.shamai.field/.MainActivity --es selftest pdf`.

## טופס שומת נזקים למילוי ידני

`forms/shumat-nezakim-fillable.pdf` הוא הטופס עם 90 שדות למילוי ב-Acrobat, Chrome או Edge, כולל גופן עברי מוטמע.
`forms/make_fillable_form.py` יוצר אותו מחדש מהטופס הריק (דורש pikepdf ו-fontTools).
